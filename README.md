# Eleni Girefi — Full-Stack Developer Portfolio

A premium, production-quality personal portfolio website engineered for **Eleni Girefi**, Full-Stack Developer & Software Engineer.

Designed with the **Graphite & Emerald** visual identity, focusing on high typography standards, subtle micro-interactions, responsive multi-page client-side routing, and clean engineering judgment.

---

## ✨ Features & Highlights

- **Graphite & Emerald Identity**: Deep charcoal palette (`#090c10`, `#0e131b`) with strategic emerald green accents (`#10b981`, `#34d399`).
- **Multi-Page Architecture**:
  - **Home**: Two-column desktop hero, headline *“Turning complex problems into elegant digital experiences.”*, portrait placeholder, featured project cards, about preview, services preview, and contact CTA.
  - **About**: Engineering background, internship collaboration, 4 engineering principles, verified skills categorized by experience level, and résumé download.
  - **Projects**: Filterable gallery (*All*, *Full-Stack*, *Cybersecurity & Tools*) with instant keyword search.
  - **Project Case Studies**: Reusable deep architectural case study template with problem statements, individual contributions, system design, key decisions, challenges/solutions, and testing insights.
  - **Services**: 6 freelance & contract service offerings with deliverables, tech stacks, and target audience.
  - **Contact**: Client-side validated form, transparent demo mode notice, instant 1-click `mailto:` launcher with prefilled subject/body, and direct profile links.
  - **Custom 404**: Clean fallback with back-to-home navigation.
- **Strict TypeScript & React 19**: Component-driven architecture with zero type errors.
- **Accessible & Responsive**: Keyboard navigable, visible focus states, skip-to-content link, semantic HTML, and zero horizontal overflow on mobile.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (strict type-checking)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/) + PostCSS + Autoprefixer
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVG brand marks

## 🚀 Quick Start

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (v18+) and npm installed.

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/elu2121/eleni-portfolio.git
cd eleni-portfolio

# Install dependencies
npm install
```

### 3. Development Server
```bash
npm run dev
```
Open [http://127.0.0.1:5173](http://127.0.0.1:5173) in your browser.

### 4. Production Build & Preview
```bash
# Type check and build bundle into /dist
npm run build

# Preview production build locally
npm run preview
```
